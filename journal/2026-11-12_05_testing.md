## Notes
* LS allows one personal access token per user (`POST /api/token/` → 409 the second time).
  The e2e fixture mints it on a fresh instance; to reuse a running instance pass `E2E_LS_PAT`.
* While iterating I killed the throw-away LS with `pkill -f <pattern>`. The pattern also
  matched the invoking shell (exit 144). Production LS (port 8081) was unaffected (verified).
  Use the PID instead.
